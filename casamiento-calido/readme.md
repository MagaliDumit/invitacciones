# Invitación de Casamiento - Estilo Cálido

Sitio web estático de invitación de casamiento (Valentina & Tomás). Una sola página (HTML + CSS + JS), con sobre animado de bienvenida, secciones a pantalla completa y estética glassmorphism. Lista para alojar en cualquier hosting.

## Estructura

```text
casamiento-calido/
├── readme.md
├── index.html
└── css/
    └── style.css
```

## Secciones

Portada, cuenta regresiva, nuestra historia, cuándo y dónde, cronograma, código de vestimenta, RSVP, música, regalos, FAQ y cierre con muro de mensajes.

## Personalización

Reemplazar los datos entre corchetes por los datos reales (nombres, fecha, direcciones, alias/CBU, etc.). La fecha del evento en el script es `2027-04-24T20:00:00`.
