# Invitación de Casamiento - Estilo Clásico

Sitio web estático de invitación de casamiento (Camila & Federico). Una sola página (HTML + CSS + JS), con sobre 3D animado de bienvenida, secciones a pantalla completa y estética glassmorphism elegante. Lista para alojar en cualquier hosting.

## Estructura

```text
casamiento-clasico/
├── readme.md
├── index.html
└── css/
    └── style.css
```

## Secciones

Portada, cuenta regresiva, nuestra historia, ceremonia y celebración, programa de la velada, etiqueta, confirmación de asistencia, música, presentes, información para invitados y libro de firmas.

## Personalización

Reemplazar los datos entre corchetes por los datos reales (nombres, fecha, direcciones, alias/CBU, etc.). La fecha del evento en el script es `2027-04-24T20:00:00`.
